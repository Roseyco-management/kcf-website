  <action>
Replace static `blogPosts` import with Supabase query:

1. Import `createClient` from `@supabase/supabase-js` (use service role for sitemap generation)
2. Initialize Supabase admin client with:
   - URL: `process.env.NEXT_PUBLIC_SUPABASE_URL!`
   - Key: `process.env.SUPABASE_SERVICE_ROLE_KEY!`
   - Options: `{ auth: { persistSession: false } }`
3. Query blog posts:
   - Select only slug and updated_at (or published_at if updated_at is null)
   - Order not required (sitemap doesn't need ordering)
4. Map to sitemap format:
   ```typescript
   ...posts.map((post) => ({
     url: `https://www.kcfhomes.com/blog/${post.slug}`,
     lastModified: post.updated_at || post.published_at,
     changeFrequency: 'monthly' as const,
     priority: 0.8,
   }))
   ```
5. Handle query errors gracefully: if Supabase fails, return empty array for blog posts (don't break entire sitemap)

AVOID using `blogPosts` import from `src/data/blog-posts.ts`.

Use service role client (not SSR client) since sitemap generation happens at build time without request context.
